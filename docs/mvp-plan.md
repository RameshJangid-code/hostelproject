# MVP Planning Notes

## Primary Users
- Students searching hostels in Jaipur
- Hostel owners uploading and managing their properties
- Admin who verifies data and monitors platform activity

## Core User Flows

### Student Flow
1. Student signs up with mobile number.
2. Student opens hostel listing page.
3. Student searches by area like Vaishali Nagar, Malviya Nagar, Mansarovar.
4. Student applies filters.
5. Student opens hostel detail page.
6. Student reads photos, facilities, rules, timings, food ratings, reviews.
7. Student saves hostel to wishlist or contacts owner.

### Owner Flow
1. Owner signs up.
2. Owner opens dashboard.
3. Owner adds hostel details, rent, room type, images.
4. Owner updates seat availability.

### Admin Flow
1. Admin reviews listings.
2. Admin verifies approved hostels.
3. Admin tracks most viewed / most enrolled hostels.

## Recommended MVP Scope

### Include now
- Authentication
- Listing, search, filter, detail page
- Owner dashboard
- Reviews
- Wishlist
- Seat availability

### Delay until later
- Payments
- Coupons
- Ads
- Real-time chat
- Multiplayer games
- Community feed
